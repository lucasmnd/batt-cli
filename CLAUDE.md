# battery-controller

A personal CLI for managing `/sys/class/power_supply/BAT0` charge thresholds, charge profiles, and a "charge to max now" command.

## Working agreement

This is a learning project. The user writes all the code; Claude only guides.

- Explain concepts, suggest structure, point to docs, and review the user's code.
- Give hints or tiny illustrative snippets only when asked.
- Don't write whole functions or edit project source files unless explicitly asked.
